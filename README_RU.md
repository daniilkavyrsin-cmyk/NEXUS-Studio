# NEXUS Studio 0.6.0 — Android prototype

## Реализовано
- Стили Material You, Liquid Glass, AMOLED, монохром и оригинальный.
- Раздельные цвета символа и фона, HEX, прозрачность стекла, формы и масштаб.
- Импорт пользовательских изображений в демонстрационные иконки с сохранением URI.
- Сохранение параметров оформления в SharedPreferences.
- Каталог стилей и новый экран обнаружения приложений с ярлыками запуска (название и package name).

## Ограничения
- Экран приложений пока только обнаруживает ярлыки запуска; назначение заменённых значков системному лаунчеру ещё не реализовано.
- PNG-экспорт, генерация MTZ и изменение Control Center HyperOS пока не реализованы.
- Список приложений зависит от видимости пакетов Android и может быть ограничен прошивкой.

## Сборка
Откройте проект в Android Studio, установите Android SDK 35 и выполните Build → Build APK(s).
Минимум Android 8.0 (API 26), target SDK 35. Проект требует сборки и проверки на реальном устройстве.


## Версия 0.5.0
- Вкладка «Приложения» позволяет назначать отдельные изображения конкретным установленным приложениям (ключ — package name).
- Назначения и URI изображений сохраняются локально.
- Добавлен экспорт ZIP: папка `icons/` с исходными изображениями и `manifest.json` с привязками.
- Экспорт не устанавливает иконки в системный лаунчер: ZIP — подготовленный набор ресурсов для следующего этапа интеграции с форматом тем.

## Автоматическая сборка APK
В проект добавлен workflow GitHub Actions (`.github/workflows/build-apk.yml`). После загрузки проекта в GitHub откройте вкладку **Actions**, выберите **Build NEXUS Studio APK** и нажмите **Run workflow**. После успешной сборки скачайте артефакт **NEXUS-Studio-debug-APK** — внутри будет `app-debug.apk`.

Это debug-сборка для установки и тестирования, не подписанный релиз для публикации. Сборка и совместимость с HyperOS должны быть проверены на устройстве.


## Версия 0.6.0
- Экспорт назначенных иконок теперь нормализует изображения: квадратное кадрирование по центру, PNG 512×512.
- ZIP использует расширение `.png` и содержит `manifest.json` с package name.
- Обновлена версия приложения и описание экрана «Система».
- Сборка APK выполняется через GitHub Actions; результат доступен как артефакт `NEXUS-Studio-debug-APK`.

## Получение APK с телефона
1. Создайте репозиторий на GitHub и загрузите содержимое папки `NEXUS_Studio_Android`.
2. Откройте **Actions → Build NEXUS Studio APK → Run workflow**.
3. После зелёного статуса сборки откройте запуск workflow и скачайте **NEXUS-Studio-debug-APK**.
4. Распакуйте скачанный архив и установите `app-debug.apk`, разрешив установку из этого источника.

APK не может быть собран в текущей среде: здесь отсутствуют Android SDK и Gradle. Workflow выполняет сборку в облачной среде GitHub.
